# Роли моделей и подтверждённые данные

[English](model-roles.md)

Проверено: **2026-10-27**. Каталог показывает существующие настройки и кандидатов
из документации. Его чтение не запускает модели и не проверяет доступ аккаунта.

```powershell
python codex-flow.py workflow models
python codex-flow.py workflow models --json
```

| Модель | Роль и effort в каталоге | Запуск через Flow | Подтверждение |
| --- | --- | --- | --- |
| `gpt-6.1-sol` | Главный агент / `xhigh` | Существующий вариант по умолчанию | Ранее подтверждён нативный запуск Flow |
| `gpt-6-luna` | Необязательный исполнитель / `medium` | Существующая дополнительная настройка | Ранее preflight получил HTTP 429 до запуска дочернего агента |
| `gpt-6.1-terra` | Проверка визуальных материалов, локальная правка кода / `medium` | Отключён | Кандидат из документации; аккаунт и качество на наших задачах не проверены |

`default_effort` относится к ролям этого каталога. Главной моделью остаётся Sol;
добавление Terra не разрешает подмену модели или её запуск. Нативные эксперименты
остаются на паузе. Флаг запуска отражает существующий код, а не разрешение выполнить
workflow. Статус проверки описывает прошлые запуски Flow, а не текущий доступ аккаунта.
У всех трёх моделей `native_account_verified: null`: каталог не проверяет аккаунт
вызывающего пользователя. Исторический ответ 429 у Luna не доказывает недоступность модели.

OpenAI описывает Terra как модель для анализа изображений и экранов, управления
компьютером и работы с текстом; effort по умолчанию — `medium`. Руководство по
выбору модели также предлагает рассматривать её для локальных исправлений кода.
Это основание сохранить кандидата. Преимущество над Sol на задачах этого проекта
не подтверждено. Источники: [страница Terra](https://developers.openai.com/api/docs/models/gpt-6.1-terra)
и [руководство по выбору моделей](https://developers.openai.com/api/docs/guides/model-selection).

Согласно [официальному руководству](https://learn.chatgpt.com/docs/models), Terra
требует CLI **0.159.0+**. `catalog(cli_version=...)` проверяет переданную полную
версию, допускает префикс `codex-cli ` и не запускает CLI. Без версии поле
`cli_compatible` равно `null`; для некорректной или старой версии — `false`.
Предварительный выпуск 0.159.0 ниже минимальной версии. Совместимость версии
не подтверждает доступ аккаунта, квоту, инструменты или успешное выполнение.

[Заметка о выпуске 26 октября](https://learn.chatgpt.com/docs/whats-new/october-26-30-2026)
сообщает о Terra в Work и Codex на планах Plus, Pro, Business, Enterprise и Edu.
Фактический доступ зависит от продукта, версии и настроек администратора рабочей
области. Поэтому у всех моделей сохранено `native_account_verified: null`.
Каталог не заявляет экономию подписки или стоимость и не обращается к платному API.
