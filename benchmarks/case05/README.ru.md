# Case05: наблюдаемые результаты и границы

[English](README.md) · [Метрики](results.json) · [Хеши](evidence-hashes.json) · [Проверенные исходники](solutions/README.ru.md) · [Файлы исходников](source-manifest.json) · [Протокол](../protocol/)

Отдельный эксперимент с замороженным runtime 343d395: Sol 6.1 XHigh, порядок A/B, затем C/D. Слепая оценка завершила 26 критериев и пять критических условий; принятых артефактов: 4/4. Приёмка артефакта не меняет исходного статуса процесса.

Помощник подтверждается связью родитель→потомок в native-метаданных, не запрошенной моделью/effort. Неизвестное число остаётся null. Локальные Harness²-inspired пробы не равны upstream-исполнителю; единичные вызовы Mercury не доказывают качество маршрутизации.

Полный aggregate публикуется только при завершённых запросах всех фаз с известным usage. Нижние границы завершённых запросов сохранены отдельно; накопительные бюджетные счётчики не складываются. Деньги/квота неизвестны, если не измерены. RSS/CPU — выборочные root/probe PID, без потомков и удалённой модели.

Frozen-discovery, ошибки тестов и terminal-сценариев сохранены. Если дополнительные CLI-проверки не выполнялись, указан not_run; их результаты не выдумываются. Лимит времени не равен времени завершения. Это отдельный case, не объединённый с 02/04; проценты ускорения и причинный вклад не вычисляются.

Лучший балл в этой попытке получил A. У B нет обязательной документации, проверка Ctrl+C в ConPTY закончилась таймаутом; Q и Escape работали. У C нет документации, экспорт отстаёт от текущего вида на кадр. У D сохранены три ошибки отсутствующей `.tmp` при замороженной команде тестов и ссылка на отсутствующий validation-документ. Все четыре прошли 16 независимых проверок геометрии: объёмный каркас ветвей, переменную W и точные гиперповорот/перспективу. Native-проверки: A/D — 57 успешных; B — 55 успешных и диагностический таймаут Ctrl+C, две оставшиеся проверки не оценены; C — 46 успешных, 11 неуспешных. Генератор D завершился с `upstream_open_error` без HTTP-ответа; точная сетевая причина неизвестна, повторов не было.

Полный usage всех фаз известен только для A: 1 415 382 входных и 46 482 выходных токена, включая 267 776 кешированных входных. Суммы B/C/D оставлены null; в JSON сохранены нижние границы завершённых запросов. Mercury сообщил стоимость 0 для двух проверенных бесплатных вызовов. Деньги и изменение квоты подписки неизвестны. Преимущество производительности из этих наблюдений не следует.

Все [127 опубликованных файлов приложений](source-publication.json) сохраняют проверенные байты; исключены пять исходных self-report логов. В [полном независимом review](blind-review.json) скрыты только локальные пути; баллы, условия и приёмка не менялись. Оригинальный review неизменяем; отдельный адаптер формата сопоставляет числовые ID с именами каталогов для упаковки. [Аудит собственных native-сессий](../../docs/evidence/case05-owned-session-audit.json) ограничен своим scope и не доказывает физическую изоляцию чтения или жёсткую глубину.
