# ASCII Tree Explorer

Интерактивное процедурное дерево: один граф ветвей в **2D, 3D и 4D**.
Только стандартная библиотека **Python 3.12+**, без установки пакетов, сети,
GPU и API-ключей. Основная платформа — Windows 11, Windows Terminal,
PowerShell 7. POSIX-адаптер предусмотрен для Linux/WSL, но в этой среде
проверен только Windows.

## Запуск

Откройте PowerShell в каталоге проекта:

```powershell
python --version
python -m ascii_tree --help
python -m ascii_tree view --seed 42 --mode 3d
```

Установка через pip не нужна; `requirements.txt` фиксирует отсутствие
сторонних зависимостей. `python ascii-tree.py ...` — равнозначный launcher.
Команды в документации используют фактический entrypoint `python -m ascii_tree`.

Для подробной кроны удобно окно **100×40** или больше и обычный моноширинный
шрифт с высотой символа примерно вдвое больше ширины. При запуске анимация
приостановлена; нажмите Space. Размер окна отслеживается автоматически.
Кадры обновляются на месте в альтернативном экранном буфере; после выхода
возвращаются курсор, прежний экран и режимы консоли.

## Управление

- `1` / `2` / `3` — 2D / 3D / 4D. Объект и seed сохраняются.
- Стрелки — вращение и наклон камеры в 3D/4D; `[` / `]` — XW-поворот в 4D на 10°.
- `+` / `-` — масштаб; `=` также увеличивает. `Space` — анимация/пауза.
- `G` — новое дерево и видимый новый seed; `R` — исходные углы, масштаб и время.
- `E` — экспорт; `H` / `?` — справка; `Q` / `Esc` / `Ctrl+C` — выход.

Буквенные клавиши используйте в английской раскладке, регистр не важен.
В справке стрелки и Enter листают страницы, `H` закрывает её. Это позволяет
прочитать help и в узком окне. В 2D камера зафиксирована на XY, стрелки и
XW-клавиши ничего не меняют; масштаб, ветер, seed и экспорт работают.

В 4D интерфейс явно показывает `XW` и пояснение `4D -> 3D -> 2D`.
Анимация добавляет общий ветер, вращение камеры (3D/4D) и XW-поворот (4D).
В открытой справке время анимации заморожено. `R` сохраняет выбранный режим,
seed и состояние play/pause.

## Headless CLI и экспорт

```powershell
python -m ascii_tree render --seed 42 --mode 2d --width 100 --height 40 --output tree-2d.txt
python -m ascii_tree render --seed 42 --mode 3d --yaw 50 --pitch 15 --output tree-3d.txt
python -m ascii_tree render --seed 42 --mode 4d --angle4 0 --width 100 --height 40 --output before.txt
python -m ascii_tree render --seed 42 --mode 4d --angle4 45 --width 100 --height 40 --output after.txt
python -m ascii_tree render --seed 7 --mode 4d --yaw 20 --pitch 10 --angle4 30 --zoom 1.2 --time 1.25 --output seed7.txt
```

`--yaw`, `--pitch`, `--angle4` заданы в градусах. `--time` — фиксированное
время анимации в секундах, по умолчанию 0. Все случайности используют только
локальный `Random(seed)`. Одинаковые аргументы дают одинаковые байты при
повторных запусках; время часов и глобальный random на кадр не влияют.

`--width`: 1…500; `--height`: 1…200; `--zoom`: 0.1…8. Параметры с NaN/Infinity
отклоняются. Если `--output` не указан, чистый кадр идёт в stdout; сообщения
об ошибках идут в stderr. `render` всегда обходится без TTY. Если `view`
запущен с перенаправленным вводом **или** выводом, он печатает один кадр,
сообщает о fallback в stderr и завершается. Зависания в CI не происходит.

Все пиксели кадра — печатаемые ASCII 32…126; единственный разделитель строк —
байт LF. Каждая строка имеет ровно `width` символов, включая конечные пробелы,
каждый файл содержит ровно `height` строк с завершающим LF. Цветов, ANSI,
подписей и UI в экспортируемом растре нет.

В интерактивном режиме `E` сохраняет текущую область дерева в `exports/`.
Имена включают seed, режим и свободный порядковый номер; прежние экспорты
не перезаписываются. Каталог меняется через `view --export-dir my-frames`.
Размер интерактивного экспорта соответствует области дерева, а не всему
окну: в окне 100×40 это 100×34 (пять строк UI и одна защитная строка).
Для точного размера 100×40 используйте `render`. Ошибка записи показывается
в статусе, приложение продолжает работать.

## Как устроены режимы

Генератор выращивает искривлённый ствол с расширением у основания,
асимметричные радиальные скелетные ветви, четыре порядка ветвления и
объёмные разреженные группы листвы. У сегмента есть начало, конец,
положительные радиусы и индекс предка. Начало дочернего сегмента в точности
совпадает с концом родительского. Геометрия создаётся один раз; только `G`
вызывает генератор снова.

**2D** — ортографическая проекция XY того же объекта. **3D** — реальная
геометрия XYZ, yaw/pitch, перспективная проекция, z-buffer для ветвей и
листьев. Толщина, расстояние и цилиндрическая подсветка выбирают ASCII-тон;
направление тонких ветвей читается по `/`, `\`, `|`, `-`.

**4D** — у каждой вершины есть `(x,y,z,w)`. W накапливает длину пути роста
от основания, с поправкой на порядок ветви, и не является константой.
Сначала координаты центрируются, затем применяется настоящий XW-поворот:

```text
c = cos(angle4), s = sin(angle4)
x' = c*x - s*w
y' = y
z' = z
w' = s*x + c*w

f4 = 40 / (40 - w')
(X,Y,Z) = f4 * (x',y',z')             # 4D -> 3D
(Xc,Yc,Zc) = camera_yaw_pitch(X,Y,Z)
f3 = 45 / (45 - Zc)
screen = (cx + 2*scale*f3*Xc, cy - scale*f3*Yc)  # 3D -> 2D
```

Матрица XW ортогональна, имеет определитель +1 и смешивает X с W.
Положительный Zc ближе к камере. Z-buffer сравнивает глубину для каждого
символьного пикселя. Знаменатели проверяются до деления, линии ограничены
экраном. Множитель 2 по X учитывает пропорции терминальной ячейки.
Терминал показывает **проекцию 4D-данных**, а не физический четырёхмерный экран.

## Проверки и примеры

Полный набор автоматических тестов:

```powershell
python -m unittest discover -s tests -v
```

Воспроизводимый конечный smoke test одной командой, без TTY:

```powershell
python scripts/smoke.py
```

Конечный тест настоящего Windows TTY, запустить непосредственно в терминале:

```powershell
python scripts/tty_smoke.py
```

Он вводит события только в собственную консоль, проверяет режимы, стрелки,
XW, масштаб, help, play/pause, экспорт, выход через Q/Esc/Ctrl+C и точное
восстановление исходных console mode flags. Завершается самостоятельно.
Без Windows или без TTY явно сообщает `NOT RUN`, код выхода 2.

В `samples/` сохранены по четыре кадра seed=42 и seed=7: 2D, 3D, 4D при XW=0°
и 45°. `manifest.json` содержит параметры и SHA-256 каждого файла. Smoke
сверяет их с заново отрендеренными кадрами.

```powershell
python scripts/make_samples.py
python scripts/benchmark.py
Get-Content samples/seed42-2d.txt
Get-Content samples/seed42-4d-xw045.txt
```
