# Фактические проверки

Проект проверен 2026-10-23 в выделенном Windows-workspace,
**CPython 3.12.10, PowerShell 7, Windows ConPTY**. Сеть, сторонние пакеты,
API, дополнительные модели и другие workspace не использовались.

## PASS

1. **37 автоматических тестов**, `python -m unittest discover -s tests -v`.
   Детерминизм геометрии и кадров, несколько seed, положительные длины и
   радиусы, связность и конечность графа, tapering, реальные Z/W, размеры
   80×30 и 100×40, только ASCII, точные байты LF, безопасные маленькие окна.
   Проверены повороты 3D, порядок occlusion по реальному символу пересечения,
   ортогональность и определитель XW-матрицы, обратный поворот, перенос W в X,
   влияние W-перспективы и XW на кадр, сохранение объекта при смене режима.
   CLI запускается отдельными процессами с timeout; покрыты fallback без TTY,
   файловые ошибки, невалидные параметры, детерминированное время, пауза,
   завершение, восстановление контекста при KeyboardInterrupt и Ctrl+C.
   Полный вывод: `verification/unittest.txt`.
2. **Headless smoke 5/5**, `python scripts/smoke.py`.
   Запуск/help, все режимы, повторяемые экспорты, разные seed и XW-углы,
   минимум 1×1, view без TTY, все 8 сохранённых кадров. SHA-256 и свежие
   CLI-рендеры совпали с файлами в `samples/`. Вывод: `verification/smoke.txt`.
3. **Настоящий Windows TTY**, `python scripts/tty_smoke.py` с TTY.
   Через WriteConsoleInputW поданы события в собственную консоль: режимы,
   стрелки, XW, масштаб, help, play/pause, E, Q, Esc, Ctrl+C. Проверены
   неизменность объекта, разные экспортированные проекции, восстановление
   **обоих исходных console mode flags** после каждого вида выхода.
   Отчёт: `verification/native-tty.json`. Во внешнем ConPTY отдельно введены
   режимы, стрелки, масштаб, справка, анимация, G, R, E, Q и Ctrl+C;
   экспорт после стрелок совпал байт-в-байт с ожидаемой ориентацией.
4. **Сохранённые артефакты**: seed=42 и seed=7, по 2D, 3D и двум 4D-кадрам
   с XW=0°/45°, все 100×40. Параметры и хеши: `samples/manifest.json`.
   Кадры осмотрены как текст: читаются основание, ствол, скелетные ветви,
   разветвления и асимметричная крона; XW заметно меняет форму проекции.
5. **Конечный benchmark**, `python scripts/benchmark.py`: 48 кадров 100×40,
   seed=42/7, 2D/3D/4D. Медианы 34.14–63.98 мс, максимальный замер 71.06 мс.
   Измерения выполнялись после тестов, без параллельной тестовой нагрузки.
   Полные результаты: `verification/benchmark.json`. Анимация ограничена
   сверху 10 FPS; реальная частота зависит от терминала и CPU.

Дополнительно проверено сохранение отрицательного CLI pitch при переходе
к интерактивному управлению: -10° и стрелка вверх дают -5°, без скачка к 80°.

## FAIL, исправленный до итогового прогона

Первоначальный Windows-ввод через `msvcrt.getwch()` не завершал приложение
по Ctrl+C в данном ConPTY. Он заменён на raw KEY_EVENT_RECORD через Win32
с восстановлением исходного input mode. Повторный внешний Ctrl+C завершил
приложение, нативный автоматический тест подтвердил очистку и возврат
обоих режимов консоли. В итоговых тестах не осталось FAIL.

## NOT RUN и ограничения

- **Физический resize Windows Terminal** мышью/границами окна: не выполнялся.
  Смена размеров 100×40 → 80×30 → 8×3 → 1×1 → 100×40 прошла в реальном цикле
  приложения с подставным терминалом; отдельные проверки покрывают маленькие
  размеры и пагинацию help. Ручной сценарий — `INTERACTIVE_CHECK.md`.
- **Linux/WSL и POSIX TTY**: не запускались. Разбор разделённых VT-последовательностей
  и отдельного Esc проверен модульно; полноценная termios-интеграция не заявляется.
- **Скриншоты, видео и визуальные UI-тесты браузером**: не выполнялись.
  Приложение терминальное; демонстрация поставляется воспроизводимым сценарием,
  нативным TTY-smoke и экспортированными ASCII-кадрами.
- **Все возможные seed, шрифты, эмуляторы и длительная анимация** не исчерпаны.
  Нативный тест конечный; длительный soak-test не запускался. На 1×1 гарантируется
  отсутствие падения, а не удобство чтения. Near-plane clipping, точки листвы
  и фиксированный aspect ratio имеют ограничения из IMPLEMENTATION_NOTES.md.
