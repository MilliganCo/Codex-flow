# Демонстрация интерактивности

Запуск в Windows Terminal / PowerShell 7:

```powershell
python -m ascii_tree view --seed 42 --mode 2d
```

Один проход занимает примерно **90 секунд**:

1. Выставьте около 100×40 символов. Нажмите `E`, `2`, `E`, `3`, `E`.
   Заголовок меняет режим, seed остаётся 42; дерево сохраняет общую структуру.
   В `exports/` появляются три чистых ASCII-кадра.
2. Нажмите `]` четыре раза, затем `E`. XW=40° меняет форму проекции.
   Проверьте стрелки, `+`, `-`, затем `R`: исходные углы и масштаб возвращаются.
3. Нажмите Space, посмотрите 5 секунд, снова Space. Кадр меняется на месте,
   после паузы останавливается. Нажмите `H`, прочитайте объяснение 4D,
   закройте help; `G` меняет seed и форму дерева, `E` сохраняет новый кадр.
4. Уменьшите окно примерно до 25×10, затем верните 100×40, включая изменение
   размера при анимации. Ожидается перерисовка без исключений и старых строк.
   В узком help листайте стрелками/Enter. На размерах 1×1…8×4 гарантируется
   только безопасная работа; значимое изображение и полное управление не помещаются.
5. Выйдите через `Q`. Повторно запустите и проверьте `Esc`, затем ещё раз
   запустите и нажмите `Ctrl+C`. Курсор и исходный экран должны восстановиться,
   команды PowerShell должны снова вводиться с обычным echo.

Автоматическая демонстрация настоящего Windows-ввода занимает примерно
**2 секунды** и завершается без участия пользователя:

```powershell
python scripts/tty_smoke.py
```

Она сохраняет результат в `verification/native-tty.json`. Это проверка
нативных событий клавиатуры и консоли, а не видеозапись. В этой среде
также был выполнен ручной ввод через Windows ConPTY, включая стрелки,
режимы, экспорт, анимацию, Q и Ctrl+C. **Физическое изменение размера окна
не выполнялось**; resize и крошечные размеры покрыты автоматическим
сценарием контроллера. Скриншоты и видео не создавались.
