# Замороженные приложения case05

[English](README.md) · [Независимые результаты](../README.ru.md) · [Точные хеши](../source-publication.json)

Это проверенные Windows-снимки эксперимента. Их не исправляли после оценки. Все 127 опубликованных файлов сохраняют исходные байты. Исключены пять исходных self-report логов, native/Git/auth-состояние, кеши и временные результаты проверок. ASCII-примеры сохранены. Некоторые ссылки исходных README на исключённые логи могут быть недоступны; недостающая документация и дефекты отражены в оценке.

| Каталог | Условие | Балл /100 | Известное ограничение |
|---|---|---:|---|
| `A` | Один Sol XHigh | 97 | Плотная крона; часть 4D-ракурсов обрезается сверху |
| `B` | Flow: помощник, Mercury и локальные пробы | 89 | Нет обязательной документации; Ctrl+C не завершил процесс в проверенном ConPTY |
| `C` | Flow без локальных проб | 89 | Нет обязательной документации; экспорт отстаёт на один кадр |
| `D` | Flow без Mercury | 94 | Три ошибки `.tmp` при замороженной команде тестов; одна ссылка документации отсутствует |

Все прошли пять критических условий геометрии и запуска. Это не означает успешного прохождения каждой проверки. Статусы генераторов, сбой транспорта и лимиты времени сохранены отдельно в [отчёте](../README.ru.md). CI на двух платформах относится к поддерживаемым примерам; эти неизменённые снимки исполнялись при независимой проверке на Windows.

Запуск одиночного варианта из корня репозитория — без модели и установки пакетов:

```powershell
Push-Location benchmarks/case05/solutions/A
python -m ascii_tree view --seed 42 --mode 4d
Pop-Location
```

Для другого снимка выберите `B`, `C` или `D`. `1`/`2`/`3` переключают измерения, `[`/`]` вращают в 4D, `Q` или Escape завершают работу. Для B в описанном ConPTY используйте эти проверенные клавиши выхода. Доступны также `python -m ascii_tree --help` и `render`.

Оценщик, рубрика и задание не менялись; публикация не меняет баллы или оригинальные исходники. Отдельные [демо case02](../../../examples/ascii-tree/README.ru.md) имеют Windows/Ubuntu CI и явно отмеченное исправление fingerprint для проверенных платформ.
