# Проверка интерактивности за две минуты

Запуск в Windows Terminal / PowerShell 7 из корня проекта:

```powershell
py -3.12 -m ascii_tree view --seed 42 --mode 3d
```

1. **0–25 секунд:** нажмите `1`, затем `2`, несколько раз стрелку вправо/вверх. Видно одно дерево с разными проекциями, seed остаётся 42. В 2D стрелки не вращают фиксированную фронтальную проекцию.
2. **25–50 секунд:** нажмите `3`, затем `]` пять раз. В заголовке XW=40°, крона и ствол меняют проекцию. Нажмите Space, наблюдайте 5 секунд и снова Space. Изображение обновляется на месте.
3. **50–75 секунд:** нажмите `+`, `-`, `E`, `H`, `H`, `R`. Экспорт появляется в `exports/`; справка объясняет 4D→3D→2D. После R углы сброшены, seed тот же. Нажмите G: seed=43, дерево другое.
4. **75–100 секунд:** уменьшите окно примерно до 20×6, затем верните 100×40. Падения и прокрутки кадров быть не должно; дерево возвращается. Нажмите Q — обычный prompt и курсор восстановлены.
5. **100–120 секунд:** запустите ещё раз, выйдите через Ctrl+C. Введите `Write-Output terminal-ok`: prompt должен принимать обычный ввод. Дополнительно можно повторить выход через Esc.

Экспорт содержит только дерево, без заголовков. Проверьте его командой:

```powershell
Get-Content exports/tree_42_4d_001.txt
```

Номер может отличаться, если экспорт уже выполнялся. Файл имеет размеры текущей области дерева, поэтому это не обязательно 100×40: интерфейс оставляет место под строки управления и обходит последнюю физическую строку/колонку терминала.

Этот сценарий приложен вместо видео. Живой PTY-сеанс и автоматические проверки описаны в `VALIDATION.md`; реальное изменение размера окна мышью в Windows Terminal требует ручного выполнения шагов выше.
