# Фактическая проверка

2026-10-23; Python 3.12.10, Windows, PowerShell 7. Все действия — в выданном
workspace, без сети и сторонних пакетов.

## PASS: автоматические проверки

Финальный `python scripts/smoke.py`: **38 тестов прошли** за 3.9 s, затем
успешно проверены все пять сохранённых кадров. Отдельная команда suite:
`python -m unittest discover -s tests -v`.

1. `test_model.py`: seed 42 детерминирован, seed 7/42/123 различаются; один
   корень, связность/ацикличность, положительные длины и радиусы, конечность,
   tapering, ограничение роста, разнообразие Z/W.
2. `test_geometry.py`: XW при 90°, ортогональность, определитель 1, норма/
   обратимость, 4D perspective и W, защита eye planes, пространственная камера.
3. `test_render.py`: 80×30, 100×40 и до 1×1; печатаемый ASCII/LF без ANSI;
   повторяемость seed/time, yaw/pitch/XW меняют проекцию, связность 2D-скелета,
   запас по вертикали в сохранённых 4D-ракурсах.
   Ближний/дальний сегменты проверены при обоих порядках рисования и смене
   глубины; отдельно проверено изменение глубины вдоль сегмента.
4. `test_state.py`: общий объект при смене режимов, G, управление/пауза/сброс,
   help, resize 100×40 → 80×30 → 1×1, ASCII-экспорт без перезаписи, lifecycle.
   FakeTerminal-тесты — симуляции, не доказательство поведения Windows API.
5. `test_cli.py`: реальные subprocess без TTY, help, повторные байты,
   stdout и .txt с LF, отказ view без TTY, ошибочные аргументы/пути, 1×1.

`python scripts/generate_samples.py --check` побайтно сверяет пять кадров и
manifest: seed 42 в 2D/3D/4D XW 0°/35°, seed 7 в 3D. Все кадры 100×40,
4040 bytes, только ASCII и LF. `python scripts/smoke.py` объединяет обе проверки.
