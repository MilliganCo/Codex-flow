# Интерактивная демонстрация

## Сценарий на 2 минуты

1. В Windows Terminal около 100×40 выполните
   `python -m ascii_tree view --seed 42 --mode 3d`. Нажмите 1, затем 2:
   меняется проекция, seed остаётся 42. Стрелки вправо/вверх меняют положение
   ветвей и их перекрытия.
2. Нажмите 3, затем ] четыре раза: меняются XW-угол и форма. H открывает
   объяснение 4D → 3D → 2D, ? закрывает. B убирает листья, повторное B возвращает.
3. Space запускает анимацию; через 3 секунды повторите Space. + и - меняют
   масштаб. R сбрасывает ракурс/время/масштаб. G меняет seed на 43, ещё G — на 44.
4. E показывает путь к .txt: после выхода откройте файл, там только дерево.
   Уменьшите окно до узкого, затем верните 100×40: приложение должно продолжить
   работу и перестроить кадр.
5. Q возвращает shell и курсор. Повторите запуск и выйдите Esc. Ещё один запуск
   завершите Ctrl+C: exit code 130. Автоматический реальный console probe:
   `python scripts/check_console.py`.

Второе дерево: `python -m ascii_tree view --seed 7 --mode 3d`.

справка, экспорт `exports/tree-42-4d-0001.txt`, Q. Для seed 7: стрелки вправо/
вверх (yaw 33°, tilt −1°), 4D, XW, анимация/пауза. После исправления raw input
отдельным реальным запуском проверен Ctrl+C: `VIEW_EXIT=130`.

и Esc: `VIEW_EXIT=0`.

после обычного выхода и после намеренного исключения; см. artifact JSON.
