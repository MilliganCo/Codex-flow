# Неизменённые приложения case06

[English](README.md) · [Независимый отчёт](../README.ru.md) · [Хеши 69 файлов](../source-publication.json)

A — одиночный Sol, 97/100; B — обновлённый Flow, 98/100. Здесь сохранены точные
исходники после оценки. Код не объединялся и не исправлялся. Общая инструкция и
медиа добавлены после оценки вне каталогов A/B. Оба приложения используют
стандартную библиотеку Python 3.12: для запуска не нужны аккаунт модели,
API-ключи, интернет или установка пакетов.

Из корня репозитория запустите Flow:

```powershell
Push-Location benchmarks/case06/solutions/B
py -3.12 -m ascii_tree view --seed 42 --mode 4d
Pop-Location
```

Для solo используйте тот же запуск в `solutions/A`. Клавиши: 1/2/3 — режимы,
стрелки — камера, [/] — XW-поворот, +/- — масштаб, Space — анимация, G — seed,
R — сброс, E — экспорт, H/? — справка, Q/Esc — выход. Оба прошли 57 реальных
проверок ConPTY, включая выход по Ctrl+C с кодом 130 и восстановление терминала.
Начальные углы и размеры области изображения у приложений различаются.

Экспорт без TTY и тесты из каталога B:

```powershell
py -3.12 -m ascii_tree render --seed 42 --mode 4d --width 100 --height 40 --angle4d 37 --output frame.txt
py -3.12 -m unittest discover -s tests -v
```

У A параметр гиперповорота называется `--angle4`, у B — `--angle4d`.
Собственные README/help сохранены. В Windows SDK прошли 52 теста A и 38 тестов B.
Linux и визуальное отображение шрифта Windows Terminal здесь не проверялись;
поддерживаемые примеры case02 проходят отдельный Windows/Ubuntu CI.

`source-manifest.json` описывает фильтр локальных ZIP. Отдельный
`source-publication.json` подтверждает 69 опубликованных файлов, включая исходные
примеры и самоотчёты. Самоотчёты не заменяют независимую оценку. Native/auth,
Git-указатели, HOME/temp/cache и журналы исключены до анонимизации. Все 69 исходных
хешей проверены после оценки и публикации.
