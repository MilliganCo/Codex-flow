# Записи бенчмарков

[English](README.md) · [Протокол и ограничения](../docs/benchmarking.md) · [Результаты case02](case02/results.json)

Здесь отдельно показаны статус процесса, оценка артефакта и фактические интеграции. Case02: `gpt-6.1-sol`/`xhigh`, параллельно A/B, затем C/D.

| Ветка case02 | Балл /100 | Полное время, с | Статус выполнения | Артефакт принят |
|---|---:|---:|---|---|
| A: одиночный агент | 95 | 1200.937 | `timed_out` | Да |
| B: запрошенный полный flow | 97 | 1201.562 | `timed_out` | Да |
| C: без локальных проб | 95 | 1040.469 | `completed_unverified` | Да |
| D: без Mercury | 96 | 1201.109 | `timed_out` | Да |

Приложения приняты по независимым проверкам и review, включая 4D-геометрию; статус процесса сохранён. Время до остановки по лимиту не равно времени завершения задачи; появление первого принятого артефакта не измерялось.

В case02 **успешных Mercury-вызовов было 0**, выполнение нативных помощников не подтверждено. B/D выполнили по две локальные пробы плана по мотивам Harness²; upstream Harness² не запускался. Причинный вклад компонентов и ускорение не доказаны. Позднее отдельный smoke подтвердил бесплатный Mercury-ответ со стоимостью 0; он не относится к интеграциям case02.

- Case01 исключён из-за гонки хеширования изменявшегося runtime.
- Case03 остановлен после создания Windows SDK каталогов для будущих deny-путей; запись неизменяема.
- Case04 завершён: независимые оценки A/B/C/D — **89/83/96/90**, все артефакты приняты. B/C выполнили по одному Mercury-вызову, B/D — по две локальные пробы; помощники не подтверждены. [Отчёт](case04/README.ru.md), [метрики](case04/results.json).

Неизвестные суммарные usage, изменение квоты и стоимость остаются `null`, а не нулём. Изоляция чтения и общего состояния ограничена. Сырые native-логи, базы, журналы и rollout/auth-контейнеры остаются локальными. [Манифест замороженных задания, протокола, оценщика и рубрики](protocol/frozen-inputs.json) содержит хеши опубликованных исходных условий. Ускорение полной архитектуры по этим прогонам не установлено.
