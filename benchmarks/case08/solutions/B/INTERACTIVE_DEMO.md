# Интерактивная демонстрация — около 90 секунд

В Windows Terminal / PowerShell 7 откройте каталог проекта. Этот сценарий предназначен для ручной визуальной проверки. Автоматическая запись реальных действий ConPTY сохранена отдельно в `artifacts/terminal-*.vt`; это поток ANSI/VT, а не чистые экспортированные кадры.

1. Запустите `python -m ascii_tree view --seed 42 --mode 2d` в окне около 100×40. Видны широкий ствол у основания, более тонкие ветви и редкая крона. Нажмите `2`, затем стрелки вправо/вверх: силуэт и перекрытия меняются, seed остаётся 42.
2. Нажмите `3`, затем несколько раз `]`. Строка `4D DATA PROJECTION` объясняет проекцию; XW меняется, дерево деформируется. Нажмите `R`, затем `[` — поворот работает и в другую сторону.
3. Нажмите `Space`, подождите 2 секунды, снова `Space`: анимация останавливается. Проверьте `+`, `-`, `H`, `?`, `E`. Файл `exports/tree-42-4d.txt` содержит только дерево; `H` и `?` открывают/закрывают справку.
4. Нажмите `G`: seed становится 43 и форма кроны меняется. Сузьте окно до примерно 20×8, затем восстановите 100×40: приложение продолжает работать и перерисовывается. Нажмите `Q`: возвращаются обычный экран и курсор PowerShell.
5. Повторите запуск, завершите через `Esc`; повторите ещё раз и завершите через `Ctrl+C`. После выхода введите `Write-Output 'terminal restored'`: ввод и курсор должны работать как прежде.

Автоматически выполнен эквивалент через настоящий Windows ConPTY: режимы, стрелки, XW, экспорт, справка, анимация, масштаб, reset, G, размеры до 1×1, Q/Esc/Ctrl+C и сравнение консольных режимов до/после. Графическое окно Windows Terminal, конкретный шрифт и ручное изменение его размера в этой среде не проверялись. Скриншоты не создавались.
