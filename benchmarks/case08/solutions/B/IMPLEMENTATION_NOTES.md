# Implementation notes

- Python 3.12, standard library only. Immutable seeded graph, shared endpoints, four bounded twig orders. W records root path distance and is shared at junctions.
- Native console input on Windows; termios/select on Linux. Alternate screen, hidden cursor, capped redraw, restored modes in finally. No browser or graphics dependency.
- Orthographic 2D; perspective 3D; true XW rotation plus two perspective stages in 4D. Near planes clamped. Character aspect is explicit.
- Per-cell depth buffer; reciprocal depth interpolation along projected lines; tapering elliptical branch strokes. Sparse leaves preserve branch readability. This is an ASCII approximation, not a physically exact cylinder renderer.
- Auto-fit each projection means a rotation may also change framing. Zoom then applies to that fit; clipping is intentional at high zoom. Raster dimensions bounded to 1000x500. Generation has fixed maximum order and a segment safety bound.
- 2D Space retains a still image; animation is camera orbit in 3D and XW rotation in 4D. G uses seed+1 for reproducible exploration. No wind or growth timeline.
- Measured on Windows 11 / Python 3.12.10, 100x40, seed 42, 15 renders per mode: median 29.92ms (2D), 20.36ms (3D), 24.78ms (4D); maximum observed 45.72ms. Exact environment and samples are in artifacts/benchmark.json. Default playback is capped at about 10 redraws/sec; idle redraws only follow input/resize. These measurements are local observations, not a performance guarantee for maximum 1000x500 frames.
- One graph has 1127 segments and 4129 leaf samples for seed 42. Projection caches shared immutable points for the duration of a frame. Work scales with projected segment length, stroke area and frame dimensions. Raster clipping bounds all writes.
- A native ConPTY test found that an inherited Windows CTRL_C-ignore state can suppress Python interruption. The app resets that per-process state and enables processed input; actual Ctrl+C now unwinds the terminal context and exits 130. Input/output console modes are measured and restored, not just inferred from exit code.
- Known limitations: auto-fit changes framing during rotation; ASCII leaves are sparse samples rather than continuous surfaces; cylinder depth is approximate; help is cropped in tiny windows; 2D has no motion; Linux/WSL and visual font appearance in the Windows Terminal GUI remain unverified. No known blocking defect in tested Windows paths.
- Independent read-only acceptance evidence was integrated into the checks: synthetic crossing-segment occlusion, numerical XW norm/matrix checks, and actual terminal lifecycle tests distinct from simulated key/state tests. The helper's initial PowerShell workspace access was blocked; the coordinator used direct Python access to the assigned directory. Global skills were inaccessible by policy; no external workspace or evaluator sources were used.
