# Проверки ASCII Tree Explorer

Среда: Windows 11 (10.0.26200), Python 3.12.10. Проверки выполнялись локально, без сети и внешних пакетов. Основной entrypoint: `python -m ascii_tree` из каталога проекта.

## Автоматические проверки

Команда: `python tools/smoke.py --terminal`. Итоговый код выхода, длительность и число тестов сохранены в [artifacts/verification.json](artifacts/verification.json), полный вывод — [artifacts/smoke.log](artifacts/smoke.log).

- **PASS — детерминизм и разнообразие:** повторная генерация seed 42; несколько разных seed; идентичные байты headless CLI при фиксированных углах/time; CLI-файл равен stdout.
- **PASS — граф:** единственный корень, каждый parent предшествует ребёнку, точное совпадение координат стыка, конечные координаты, положительные длины/радиусы, tapering внутри ветви и на переходах, ограниченная глубина, ненулевой диапазон Z/W.
- **PASS — растр:** 80×30, 100×40, 20×6, 2×2, 1×1; печатаемый ASCII, отсутствие ANSI/CR в экспорте, точные размеры и LF; aspect ratio меняет горизонтальный масштаб.
- **PASS — 3D и occlusion:** yaw/tilt меняют структуру кадра; на известной сцене ближний сегмент перекрывает дальний независимо от порядка рисования; изменение глубины вдоль сегмента меняет видимость. Это проверка z-buffer, а не только различия двух картинок.
- **PASS — 4D:** переменная W; XW-матрица ортогональна, обратима, смешивает X/W; нулевой угол — identity, поворот сохраняет норму; численная проверка последовательных проекций; кадры XW=0°/45° различаются в 1073 ячейках.

Дополнительные проверки взаимодействия и CLI:

- **PASS — состояние:** режимы сохраняют идентичность объекта дерева/seed; управление углами, zoom, reset, pause, G и выход; 2D остаётся ортографическим; help и интерфейс не выходят за размеры.
- **PASS — ошибки/жизненный цикл:** `--help`; headless render; `view` без TTY — понятный код 2; неверные размеры, NaN/Inf и mode отклоняются; имитация исключения вызывает cleanup.
- **PASS — ранний экспорт:** нажатие E до первой отрисовки сохраняет полный кадр, а не пустой файл. Это тест цикла событий с подменённым вводом, не реальная платформа.
- **PASS — артефакты:** шесть сохранённых кадров 100×40, SHA-256 из manifest, только ASCII и LF. Примеры seed 42/43 и обе стадии XW сохранены в `examples`.

## Настоящий Windows-терминал

Первый полезный платформенный запуск выполнен через PTY инструмента: приложение показало дерево и завершилось по Q с кодом 0. Затем [tools/terminal_smoke.py](tools/terminal_smoke.py) создал настоящий Windows ConPTY и запускал тот же CLI/terminal backend. Ввод не подменялся через Explorer.handle; использовались байты терминальных клавиш и реальный msvcrt.

- **PASS:** старт 100×40, 1/2/3, стрелки, XW `]`, E; экспорт каждого режима побайтно совпал с рассчитанным ожидаемым кадром для этих клавиш.
- **PASS:** H, Space play/pause, zoom, R, G; seed 42 сохраняется при переключении, G даёт 43.
- **PASS:** настоящий ResizePseudoConsole — 20×8, 8×4, 1×1 и восстановление 100×40 без падения.
- **PASS:** Q и Esc дают код 0; реальный Ctrl+C даёт 130. Проверены команды возврата курсора/основного экрана и равенство фактических GetConsoleMode до/после приложения.

Машинный отчёт: [artifacts/terminal-smoke.json](artifacts/terminal-smoke.json). VT-записи: `artifacts/terminal-1.vt`, `terminal-2.vt`, `terminal-3.vt`. Они намеренно содержат терминальные escape codes; чистые `.txt` находятся только в `examples` и экспортах.

## Исправленные дефекты

Первый тест графа обнаружил, что дочерняя ветвь могла начинаться толще конца родительской. Коэффициент tapering исправлен. Реальный ConPTY также выявил наследуемое игнорирование Windows Ctrl+C — теперь приложение включает processed input и восстанавливает доставку сигнала для своего процесса. Отдельно исправлена привязка потоков тестового процесса к CONIN$/CONOUT$, когда сам тест запущен с перенаправленным stdout. Финальная проверка раннего E защищает от пустого экспорта.

## Производительность и ограничения

15 кадров каждого режима, seed 42, 100×40: медианы 29.92 мс (2D), 20.36 мс (3D), 24.78 мс (4D), наибольшее измерение 45.72 мс. Сырая сводка: [artifacts/benchmark.json](artifacts/benchmark.json). Playback ограничен примерно 10 кадрами/с; без ввода и анимации нет потока повторных кадров. На максимальных размерах/zoom скорость отдельно не измерялась.

**NOT RUN:** Linux/WSL, установка wheel/console-script через pip, визуальная проверка конкретного шрифта в графическом Windows Terminal. Для запуска из исходников pip не нужен. Скриншотов GUI нет; приложен [сценарий ручной демонстрации](INTERACTIVE_DEMO.md). ConPTY проверяет реальное поведение консоли, но не внешний вид окна Terminal.

Известные компромиссы: приближённые толщины/глубина цилиндров, редкие листья, авто-fit при вращении, обрезанная справка в очень маленьком окне, неподвижная анимация 2D. В проверенных Windows-сценариях блокирующих дефектов не осталось.
