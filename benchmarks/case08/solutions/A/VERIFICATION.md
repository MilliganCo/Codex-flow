# Проверки готового проекта

Проверено 24 октября 2026 года в выданном Windows workspace: Python 3.12.10,
PowerShell 7, реальная Windows ConPTY. Сеть, API, установка библиотек,
дополнительные модели и браузеры не использовались.

## PASS — автоматические проверки

```powershell
python -m unittest discover -s tests -v
python smoke_test.py
```

Итог после всех изменений: **45 tests, OK**, около **4.94 с**; отдельный
smoke test — **PASS**, около **1.8 с**. Тесты и smoke выполнялись конечными
процессами, CLI-подпроцессы имеют timeout 10 с. Для однозначного рабочего
каталога тестовый запуск в управляемой оболочке использовал `os.chdir` в
назначенный workspace и `unittest` с тем же discovery, что указан выше.

1. **Генератор и математика.** Повторяемость seed 42 и независимость от
   глобального RNG; отличия seed 7/42/43/−1; связный граф, корректные родители,
   положительные длины/радиусы, tapering, ограниченный объём генерации,
   конечные координаты, ненулевые Z и W. XW-матрица смешивает X/W,
   ортогональна, имеет determinant +1 и сохраняет норму.
2. **Растер.** Все режимы при 1×1, 2×3, 12×5, 80×30, 100×40, 500×200;
   точное число строк/колонок, LF, только печатаемый ASCII, отсутствие ANSI/CR.
   Вращение/наклон 3D и XW 4D меняют сотни ячеек; 2D не зависит от камеры.
   Проверены aspect ratio, время анимации, конечные экстремальные углы,
   near-plane guards, offscreen-клиппинг и невалидные параметры.
3. **Occlusion.** Две контролируемые пересекающиеся ветки рисуются в обоих
   порядках: ближняя остаётся видимой. Отдельная проверка отличает правильную
   интерполяцию `1/z` от линейной глубины. Перестановка всех сегментов дерева
   сохраняет кадр.
4. **Состояние и терминальный цикл.** Смена режимов и камеры сохраняет
   идентичность объекта. G создаёт новый seed, работают reset/zoom/help/pause,
   ограничения углов/масштаба, экспорт без перезаписи. Сценарный адаптер
   проверяет startup, resize до 1×1 и обратно, shutdown, Esc, Ctrl+C,
   KeyboardInterrupt и очистку при неожиданном исключении. В узком окне
   экспорт совпадает с видимой областью дерева.
5. **CLI и артефакты.** Help всех команд, настоящий subprocess headless-рендер,
   побайтовое совпадение stdout/файла/API и повторных запусков; отказ view
   без TTY; внятные коды ошибок, ошибка записи, кадр 1×1. Семь сохранённых
   кадров совпадают с текущим renderer и SHA-256 в manifest; пары 4D различны.

Дополнительно: **PASS** синтаксический разбор всех 18 Python-файлов;
**PASS** настоящий вызов `ascii-tree.ps1 --help` (exit 0).

## PASS — живой интерактивный запуск

В реальных ConPTY-сеансах около 80×24 наблюдались дерево и его изменение
при переключении 2D/3D/4D. Проверены стрелки, XW 0→16°, H, G 42→43,
E с созданием чистого файла, Space и Q. Перерисовка использовала один
alternate screen; после выхода восстанавливались прежний экран и курсор.

Первый живой тест обнаружил, что processed input перехватывает Ctrl+C.
Исправление: на время приложения сохраняется и меняется console input mode;
Ctrl+C читается и обрабатывается как клавиша, затем исходный mode возвращается.
После исправления проведены два успешных живых выхода через Ctrl+C.
Диагностический запуск явно напечатал **`APP_EXIT_CODE=130`** после очистки
экрана; внешняя оболочка PowerShell отобразила свой exit code 1 для ненулевого
результата Python. Тесты проверяют возврат 130 непосредственно из приложения.

В окончательных файлах seed 42 XW 0°→55° меняет **650 из 4000 ячеек** при
одной геометрии. Все семь примеров — 100×40, 4040 байт каждый, без BOM и ANSI.
Просмотрены 2D, 3D, 4D 55° для seed 42 и 3D seed 7; видны основание,
ствол, ветвление, просветы в листве и различие крон.

## NOT RUN — границы проверки

- **Linux/WSL:** POSIX-адаптер реализован, но запуск на этой платформе не
  проводился. Нельзя заявлять подтверждённую кроссплатформенность.
- **Физический resize Windows Terminal:** изменение размеров покрыто
  сценарным адаптером; ручное перетягивание окна не проводилось. Восстановление
  layout при настоящем оконном resize оставлено в ручном сценарии.
- **Esc в живом сеансе:** покрыт тестом состояния; отдельно вручную не нажат.
  Проверены Q и Ctrl+C.
- **Сборка/установка пакета через pip:** не запускалась. Основной запуск
  напрямую из исходников и PowerShell-launcher проверены, runtime-зависимостей
  нет. Дополнительные версии Python и другие шрифты не проверялись.

Незакрытых падений в проведённых проверках нет. Ограничения точности
капсульного растеризатора, маленьких экранов и extreme zoom описаны в
[IMPLEMENTATION_NOTES.md](IMPLEMENTATION_NOTES.md). Воспроизводимый ручной
сценарий — [INTERACTIVE_DEMO.md](INTERACTIVE_DEMO.md).
