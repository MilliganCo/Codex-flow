# Сценарий интерактивной демонстрации

Откройте Windows Terminal + PowerShell 7, примерно 100×40. Команды выполняются
из корня проекта. Сценарий занимает около 90 секунд и не требует записи экрана.

```powershell
python -m ascii_tree view --seed 42 --mode 2d
```

1. **0–20 с.** Убедитесь, что видны ствол с утолщённым основанием и крона.
   Нажмите `2`, затем стрелку вправо пять раз и вверх два раза. Ветви меняют
   взаимное расположение и перекрытия; seed остаётся 42. Нажмите `R`.
2. **20–40 с.** Нажмите `3`, затем `E`, потом `]` семь раз и снова `E`.
   В заголовке XW меняется с 0° на 56°, видна подпись `4D data -> 3D -> 2D`.
   Два `.txt` в `exports/` различаются; дерево не пересоздавалось.
3. **40–60 с.** Нажмите `Space`, подождите 3 с, снова `Space`. Вращение
   останавливается без потока новых строк под приложением. Проверьте `+`, `-`,
   `H`, `H`, затем `G`: появляется seed 43. `1/2/3` сохраняют этот seed.
4. **60–80 с.** Сузьте окно примерно до 25×8, затем верните 100×40.
   Приложение остаётся работоспособным и перестраивает рисунок. Нажмите `Q`:
   старый экран и курсор восстановлены. Снова запустите и проверьте `Esc`.
5. **80–90 с.** Снова запустите и нажмите `Ctrl+C`: приложение завершается,
   курсор виден, обычный ввод PowerShell работает. `python smoke_test.py`
   дополнительно проверяет экспорт и неинтерактивный режим.

## Что действительно проверено в выданной среде

Живые сеансы PowerShell 7 / Windows ConPTY размером около 80×24:
запуск в 2D/3D/4D, переключение, стрелки (yaw 25→33 и pitch −7→−1),
XW 0→16°, справка, экспорт, G (42→43), запуск/пауза анимации, Q и Ctrl+C.
Наблюдались перерисовка того же экрана и восстановление alternate screen/курсора.
Физическое перетягивание окна и отдельный выход Esc в живом сеансе не
проверялись: resize, Esc, минимум 1×1 и исключения покрыты автоматическими
тестами состояния/адаптера. Снимки экрана или видеозапись не создавались;
вместо них приложен этот воспроизводимый сценарий.
