# ASCII Tree Explorer

Интерактивное процедурное ASCII-дерево: один и тот же объект в **2D, 3D и 4D**.
Ствол, корни, три порядка ветвления, сужающиеся ветви и разреженная листва
строятся по seed. Кадр содержит только печатаемые ASCII-символы и пробелы.

## Запуск за минуту

Нужен **Python 3.12+**. Внешних runtime-зависимостей нет: не нужны pip, интернет,
GPU, ключи или службы. Основной вариант: Windows 11, Windows Terminal,
PowerShell 7. Откройте терминал в каталоге проекта:

```powershell
python --version
python -m ascii_tree --help
python -m ascii_tree view --seed 42 --mode 3d
```

Удобный местный entrypoint с теми же аргументами:

```powershell
.\ascii-tree.ps1 --help
.\ascii-tree.ps1 view --seed 7 --mode 2d
```

Если политика PowerShell запрещает `.ps1`, используйте `python -m ascii_tree`;
настройки системы менять не нужно. `python run.py ...` также работает, в том
числе с абсолютным путём к `run.py` из другого каталога. Устанавливать пакет
необязательно. `pyproject.toml` описывает пакет и entrypoint `ascii-tree`;
версия build-backend закреплена, runtime-зависимости отсутствуют.

Рекомендуемый размер — **100×40**, моноширинный шрифт Cascadia Mono или Consolas.
Интерфейс англоязычный и ASCII, поэтому не зависит от кодовой страницы.
Linux/WSL поддерживаются через `termios`/`select`, но в данном Windows-окружении
эта ветка не запускалась.

## Управление

1. `1` — 2D; `2` — 3D; `3` — 4D. Seed и объект сохраняются при переключении.
2. Стрелки влево/вправо — обход камеры; вверх/вниз — наклон (3D/4D).
   `[` / `]` — XW-поворот на −8° / +8° в 4D. `+` / `-` — масштаб;
   `=` также увеличивает масштаб без Shift.
3. `Space` — запуск/пауза: ветер в 2D, обход камеры в 3D, обход и XW-поворот
   в 4D. `G` — следующий seed (`seed + 1`); `R` — сброс камеры, масштаба,
   XW и времени анимации. Новый seed сохраняет текущий ракурс.
4. `E` — сохранить текущий рисунок в `exports/tree-<seed>-<mode>-NNNN.txt`.
   Существующие файлы не перезаписываются. `--export-dir PATH` меняет каталог.
5. `H` / `?` — справка; `Q` / `Esc` — выход; `Ctrl+C` — прерывание с
   восстановлением курсора, экрана и режима ввода. В справке время заморожено.

В заголовке видны режим, seed, масштаб, углы и PLAY/PAUSED. Дерево занимает
остальные строки; одна колонка зарезервирована против переноса строки.
При resize кадр пересчитывается, а в очень маленьком окне остаётся сокращённый
интерфейс. Минимальные размеры безопасны, но увидеть крону в 1×1 невозможно.

## Headless CLI и чистый экспорт

```powershell
python -m ascii_tree render --seed 42 --mode 2d --width 100 --height 40 --output sample-2d.txt
python -m ascii_tree render --seed 42 --mode 3d --yaw 65 --pitch -12 --width 100 --height 40 --output sample-3d.txt
python -m ascii_tree render --seed 42 --mode 4d --angle4 55 --width 100 --height 40 --output sample-4d.txt
```

Все пространственные углы — в **градусах**. `--xw` — синоним `--angle4`.
Дополнительные параметры: `--zoom 1.0`, `--aspect 2.0` (высота/ширина ячейки),
`--time 1.5` (точное время анимации в секундах). Значения по умолчанию:
seed 42, режим 3d, 100×40, yaw 25°, pitch −7°, XW 0°, time 0.
`--width`/`--height` задают рисунок для `render`; в `view` размеры берутся
из терминала. Допустимые размеры: 1–500 колонок, 1–200 строк.

Без `--output` команда `render` пишет только кадр в stdout. Для побайтового
сравнения и экспорта в Windows используйте `--output`: файл всегда содержит
ровно `height` строк по `width` символов, включая конечные пробелы, LF после
каждой строки, без BOM, CR, ANSI и UI. Одинаковые seed, параметры и время дают
одинаковые байты на поддерживаемом Python. Терминальный вывод и моноширинный
шрифт могут отличаться между системами; файл от шрифта не зависит.

`render` не требует TTY. `view` при перенаправленном stdin или stdout сообщает
об отсутствии TTY и завершается с кодом 2, без управляющих кодов и зависания.
Неверные аргументы дают код 2, ошибка записи — 1, обычный выход — 0,
Ctrl+C — 130 (внешняя оболочка может отобразить свой код ошибки).

## Что именно означает 4D

Вершина хранит `(x, y, z, w)`. Координата W — нормированный путь роста от
основания до вершины: `w = 5 * path_length / max_path_length - 2.5`.
У листьев W берётся от узла прикрепления. W не является временем проигрывания
и не пересчитывается при переключении режима.

Сначала Y центрируется относительно высоты 6. Затем применяется настоящий
поворот в плоскости XW:

```text
x' = cos(a) * x - sin(a) * w
w' = sin(a) * x + cos(a) * w
y' = y - 6; z' = z
```

После этого — перспективная проекция из 4D в 3D:

```text
factor = 20 / (20 - w')
(X, Y, Z) = factor * (x', y', z')
```

Затем обычные yaw/pitch камеры и перспективная проекция 3D → символьная
плоскость. Деления защищены near plane. В режиме 4D масштаб кадра имеет
небольшой запас для расширения проекции. Это проекция четырёхмерных данных,
а не возможность показать четыре независимых оси на плоском экране.
W связан с ростом, поэтому это 1D граф, вложенный в 4D, а не 4D объём.

2D использует ортографический вид спереди той же геометрии; 3D использует
XYZ и камеру. Z-buffer разрешает перекрытия на уровне каждой текстовой
ячейки. Толщина и ASCII shading подчёркивают ствол, освещённую поверхность
и глубину; отдельные листья оставляют просветы между ветвями.

## Проверки и примеры

```powershell
python -m unittest discover -s tests -v
python smoke_test.py
```

Smoke test — одна конечная команда, работает без TTY и сети: проверяет
три режима, XW до/после, seed 42/7, размеры, ASCII, повторяемость,
help и отказ интерактивного запуска без терминала. Временные файлы создаются
в `.tmp/` внутри проекта и удаляются после проверки.

Сохранённые кадры находятся в [examples](examples/):

- [seed42-2d.txt](examples/seed42-2d.txt) и [seed42-3d.txt](examples/seed42-3d.txt).
- [4D, XW 0°](examples/seed42-4d-xw0.txt) и [4D, XW 55°](examples/seed42-4d-xw55.txt).
- Другой seed: [2D](examples/seed7-2d.txt), [3D](examples/seed7-3d.txt), [4D](examples/seed7-4d-xw35.txt).

Параметры и SHA-256 каждого кадра — в [manifest.json](examples/manifest.json).
`python tools/generate_samples.py` воспроизводит эти файлы.
`python tools/benchmark.py` измеряет 20 кадров для каждой из шести конфигураций.
