## Что подтверждено

Оба приложения получили 97/100: потеряны только три балла за эстетику. Оценены все 26
критериев, пройдены пять обязательных условий, headless 25/25 и настоящий терминал
57/57. Собственные тесты A/B: 45/31, все прошли. README, команды запуска и реальный
выход через Ctrl+C присутствуют у обоих; прежняя потеря восьми баллов не повторилась.

**B не завершил генерацию успешно.** Запрос 28 получил HTTP 200, но чтение тела
оборвалось через 56,594 секунды. Оставались 405 секунд и 52 запроса бюджета. Тип
исключения не записан; доказательств достижения лимита размера или времени нет.
Итоговый usage B остаётся null; данные 27 завершённых запросов — только нижняя
граница. Меньшее время до ошибки не считается ускорением или экономией квоты.

Подготовка Flow заняла 1,062 секунды. Подтверждены один нативный worker medium и одно
решение Mercury с проверенной нулевой стоимостью. MCP-бюджет: 4/4 успешных обращения,
без недоступных ответов; их количество не определяет личность вызывающего агента.
Калибровка по мотивам Harness² отложена, онлайн-проб 0. Полные границы измерений
сохранены в [анализе метаданных](evidence/orchestration-analysis.json).

## Математика и ограничения проверки

Пройдены базисные повороты 0/37/90°, норма, обратное преобразование, определитель,
ортогональность, XYZ rank 3 и изменение W на всём каркасе/модели для seed 42/137,
проверенная последовательная 4D-перспектива. В сырых geometry-отчётах сохранён fail:
по две дополнительные NaN-пробы не проходят у каждого решения. Закрытая вложенная
функция экранных координат B отдельно не вызвана; её формула проверена по исходникам,
а кадр — настоящим терминалом и headless-oracle. Дополнительные пробы не стали
новыми обязательными условиями задания.

Первая попытка geometry 15 упала из-за повторного использования имени переменной
в самом проверяющем скрипте. Сохранены неудачная попытка и отдельное исправление
трёх ссылок на имя; формулы, пороги и приложения не менялись. Отдельный audit
уточняет завышенную служебную отметку очистки потомков: нормальный выход внешнего
процесса сам по себе её независимо не доказывает.

## Запустить реальные демо

Из корня репозитория:

```powershell
Set-Location benchmarks/case08/solutions/B
python -m ascii_tree view --seed 42 --mode 4d
```

Для одиночного решения выберите `solutions/A`. Нужен Python 3.12+, внешних
runtime-зависимостей нет. Клавиши 1/2/3 — режимы; [/] — XW; стрелки — камера;
Space — анимация; E — экспорт; Q/Esc/Ctrl+C — выход. Экспорт без TTY:

```powershell
python -m ascii_tree render --seed 42 --mode 4d --angle4 37 --width 100 --height 40 --output tree.txt
```

[Шесть настоящих экспортов](comparison.png) набраны из неизменённых файлов
фиксированного оценщика, без повторного запуска или исправления приложений.
[Происхождение и SHA256](comparison-provenance.json) сохранены. Это не интерактивный
скриншот. Поведение новых оригиналов проверено на Windows; независимого Linux-запуска
для этих двух решений не было.

Локально сохранены все 70 проверенных файлов. [67 опубликованных файлов](source-publication.json)
побайтно совпадают с оценёнными; исключены только три неисполняемых VT-лога с личными
