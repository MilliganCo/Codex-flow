# Последняя серия из двух CLI-задач

[English](README.md) · [Состав доказательств](metadata-publication.json) · [Сводка серии](evidence/cohort/series-result.json)

**Solo (A) и Flow (B) завершили обе задачи; все четыре неизменённых приложения
получили 100/100. Цель ускорить работу без потери качества не достигнута.**
Наблюдаемое время Flow больше примерно на 20,0% для Ledger и на 30,5% для SafeZip.

| Задача | A, с | B, с | Физические запросы A/B | Завершённые запросы A/B | Независимая оценка A/B |
|---|---:|---:|---:|---:|---:|
| LedgerReconcile | 599,609 | 719,281 | 13 / 23 | 13 / 22 | 100 / 100 |
| SafeZip | 925,687 | 1207,984 | 15 / 23 | 15 / 23 | 100 / 100 |

Все четыре native-процесса завершились успешно в пределах 1500 секунд и 80
физических запросов на ветку. У Ledger B был один восстановленный сброс соединения;
неудачная попытка сохранена, её usage неизвестен. Всего — 74 физических попытки,
73 завершённые. В каждой паре прошли восемь проверок целостности контроллера;
оба списка нарушений политики пусты. Независимые SDK-оценки запечатаны до
раскрытия соответствия A/B. Публикация проверила квитанции обеих оценок и полные
составы выбранных исходников.

Заранее заданный критерий требует `время A / время B >= 1.10` для **каждой**
задачи, 100/100 и все проверки целостности и политики. Он не выполнен:
допустимые отношения A/B — **0,833623** и **0,766307**, геометрическое среднее —
**0,799257**. Отдельное [дополнение совместимости схем](evidence/cohort/series-result-schema-addendum.json)
прошло 254 проверки по 142 хешам исходных входов. Оно связывает реальные схемы
независимых печатей, полные составы исходников и SDK-квитанции. Предварительная
сводка ожидала необязательные поля, которых нет в этих схемах; несовпадение схемы
отчёта не было нарушением целостности эксперимента. Предварительная сводка
сохранена без изменений, включая консервативные null-отношения. Дополнение не
меняет задачи, критерии, оценки, исходники или результат.

## Кандидат и текущая политика

Серия использовала точные 16 файлов [замороженного runtime](frozen-runtime/),
исходный commit `f35d342ea0283d88a0befe10c3f1a4e7266e0a31`. Этот кандидат делегировал
тестовые предложения и сохранён как отклонённый. Текущие инструкции возвращают
краткий разбор рисков `reviewer/high` по переданному контексту. Главный агент
пишет и объединяет файлы приложения; shell-инструмент reviewer выключен.

[Ограниченный разбор накладных расходов Ledger](evidence/ledger04-overhead-audit.json)
фиксирует у B 20 завершённых XHigh-запросов, два High и один сброс High.
Два предложения помощника (11, затем 10 ID тестов) встраивались дважды.
У главного агента 16 команд, включая две ранние ошибки чтения, падение публичного
теста и исправление. Точных повторов команд и payload запросов нет. Это наблюдения
одного запуска, а не доказательство универсальной причины. Root-native usage
не складывается с provider usage; два XHigh-запроса провайдера не привязаны к
конкретному native-агенту.

Девять [синтетических проверок восстановления](evidence/proofs/native-rate-limit-proof-20261026-05/proof-result.json)
и отдельная [реальная native-проверка](evidence/prerequisites/efficient-prerequisite-20261026-02/prerequisite-result.json)
прошли: 24 проверки, восемь реальных запросов Sol, наблюдаемый High-помощник,
публичный CLI и SDK. Это проверка интеграции с нулевым зачётом в бенчмарке.
Восстановление включается явно; каждая физическая попытка расходует общий
лимит запросов и времени. Gateway не повторяет запросы самостоятельно;
гарантии однократного выполнения на backend нет.

## Запустить включённые CLI-демо

Независимая SDK-проверка выполнила команды демо из включённых README. Публикация
не запускала и не исправляла приложения. Из корня репозитория нужны Python 3.12
и новые пути вывода; модели, ключи и установка пакетов не требуются.
Замените `B` на `A`, чтобы открыть второе принятое решение.

```powershell
Push-Location benchmarks/efficient-cli-suite-20261026-02/solutions/ledgerreconcile/B
python -m ledgerreconcile --orders examples/orders.csv --payments examples/payments.csv --output example-report.json
Pop-Location
Push-Location benchmarks/efficient-cli-suite-20261026-02/solutions/safezip/B
python -m safezip inspect examples/sample.zip
python -m safezip extract examples/sample.zip --dest sample-output
Pop-Location
```

При повторе выберите отсутствующий файл или каталог назначения. Команды пишут
внутри выбранного каталога демо. Требования к ОС и файловой системе описаны в
неизменённых README приложений.

## Доказательства и ограничения

[Публикация Ledger](ledgerreconcile-publication.json): 17 файлов приложения,
три точных файла verifier и семь производных отчётов. [Публикация SafeZip](safezip-publication.json):
16 файлов приложения, три verifier и семь отчётов. [Публикация метаданных](metadata-publication.json)
добавляет 16 точных файлов runtime, шесть канонических входов и 46 производных
структурированных отчётов. Для оригинала и публикации указаны отдельные SHA256;
вложенные хеши квитанций относятся к исходным отчётам. Исходники не исправлялись.
Отдельный [манифест дополнения](series-addendum-publication.json) связывает ещё
один производный отчёт метаданных.

Официальный CLI — `0.164.0-alpha.11.1`, SHA256
`1103e9e09c71fa2cd0afd6d8f3b9a2d63174fe8efd7cb5bd09f1cb14ef58a098`.
Старые серии на CLI 0.163 не дают причинного сравнения. Native auth, rollout и
история общие; физическая изоляция чтения соседней ветки ослаблена. Базы, raw-логи,
stdout/stderr, приватные maps и внешние скрипты контроллера не публикуются.
Пути отчётов обезличены, хеши оригиналов сохранены. Неизвестные общий usage,
стоимость API и изменение квоты остаются null; известная нижняя граница usage
завершённых запросов подписана отдельно. HTTP использует identity; gzip не
доказывает экономию токенов или квоты.
