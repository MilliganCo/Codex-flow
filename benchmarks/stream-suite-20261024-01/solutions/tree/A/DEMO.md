# Проверка интерактивности

## Ручной сценарий, около 90 секунд

Откройте Windows Terminal + PowerShell 7 в корне проекта,
установите окно примерно 100×40, выполните:

```powershell
python -m ascii_tree view --seed 42 --mode 3d
```

1. Нажмите `1`, затем `2`, затем `3`, задерживаясь на каждом режиме на 3 секунды.
   Слева вверху меняется режим, seed остаётся 42. Внизу 4D объясняется
   последовательность XW → 3D → 2D.
2. В 4D нажмите `]` шесть раз: XW станет 45°. Крона и ствол меняют проекцию.
   Стрелки меняют ракурс; `+` и `-` меняют масштаб. Нажмите `Space`, наблюдайте
   5 секунд, затем `Space`: движение останавливается.
3. Нажмите `E`, затем `H`, затем ещё раз `E`. В `exports/` появляются два
   файла с чистым деревом; справка не попадает в файл. Закройте справку `H`.
   Нажмите `R`: yaw 25°, pitch −8°, XW 0°, zoom 1, PAUSED.
4. Нажмите `G`: seed 43, другое дерево. Уменьшите окно до 24×10 и верните
   100×40. Изображение должно обновиться без падения и скроллинга кадров.
   Справка на маленьком окне может обрезаться.
5. Выйдите через `Q`. Ещё два раза запустите ту же команду и выйдите через
   `Esc`, затем `Ctrl+C`. После каждого выхода виден курсор и работает
   обычный ввод PowerShell. Для проверки WinAPI выполните `python tools/tty_probe.py`.

Для независимого сравнения 4D:

```powershell
python -m ascii_tree render --seed 42 --mode 4d --angle4d 0 --output before.txt
python -m ascii_tree render --seed 42 --mode 4d --angle4d 45 --output after.txt
```

Откройте файлы моноширинным шрифтом или сравните готовые
[before](samples/seed42-4d-xw000.txt) / [after](samples/seed42-4d-xw045.txt).

## Воспроизводимый storyboard

```powershell
python tools/demo.py
```

[artifacts/demo/events.json](artifacts/demo/events.json) содержит список
клавиш и девять полученных экранов: старт 3D, 2D, 4D, XW 45°, поворот/масштаб,
справка, узкий размер, сброс, новый seed. Кадры создаются настоящими
обработчиками `Explorer.handle_key` и `Explorer.screen`. До `G` дополнительно
проверяется идентичность объекта дерева. Это детерминированный storyboard
без TTY; он не выдаётся за захват экрана работающего Windows Terminal.

## Что уже проверено в этой среде

В настоящем Windows PTY, PowerShell 7, viewport 80×25:
запуск, переходы режимов, стрелки вправо/вверх, `]`, `+`, проигрывание и
пауза, справка, `G`, `R`, два экспорта, выход через Q, Esc и Ctrl+C.
Экспортированные кадры имели 79×17: учтены панели и защитная строка/колонка.
После исправления Ctrl+C каждый путь выхода вернул код 0.
`tools/tty_probe.py` прошёл в настоящем PTY и сравнил режимы консоли
до/после побитно.

Изменение размера проверено автоматически через терминальный адаптер
100×39 → 12×5 и отдельно через compositor до 1×1. Физическое перетаскивание
границ окна Windows Terminal здесь не выполнялось; шаг 4 остаётся
ручной проверкой. Настоящий Linux/WSL TTY в этой среде не проверялся.
