# Verification report

Проверено 2026-10-24 в выданном workspace, Python **3.12.10**, Windows 11
build 26200, PowerShell 7. Сетевые запросы, установка пакетов и чужие ветки

## PASS — автоматические проверки

```powershell
python -m unittest discover -s tests -v
python tools/smoke.py
python tools/verify.py
```

**34 теста проходят**; последний полный прогон — 3.746 с для unittest.
`tools/verify.py` сохраняет полные stdout/stderr, платформу и результат в
[`verification/automated.json`](verification/automated.json). Smoke работает
конечно, без TTY, и проверяет все три CLI-режима, XW-изменение и tiny view.

1. **Генератор:** повторяемость seed 42; различия seed 0/42/137/−5; конечные
   координаты древесины и листьев; положительные длины/радиусы; родительский
   граф без циклов, точное совпадение стыков, tapering внутри и между ветвями;
   ограничение числа сегментов; ненулевой разброс Z и W.
2. **Рендер:** 80×30, 100×40 и размеры вплоть до 1×1 во всех режимах; ASCII
   без ANSI; изменения yaw/pitch. Перекрещивающиеся ветви проверяются в
   z-buffer и через настоящий `render()`: ближняя ветвь закрывает дальнюю,
   перестановка порядка отрисовки не меняет результат. Проверена непрерывная
   тонкая ветка между символьными строками.
3. **4D и численные границы:** переменный W; XW смешивает X/W, сохраняет норму
   и имеет ортогональную невырожденную матрицу; кадры при 0°/45°/90° различны.
   Проверены NaN/±Infinity, огромные конечные углы, нулевые/почти нулевые
   перспективные знаменатели, near-plane непосредственно через production
   renderer, пустое дерево, неверные размеры, zoom/aspect и malformed points.
4. **CLI и файлы:** реальные subprocess-вызовы help/render/view; неинтерактивный
   view завершается после одного кадра; одинаковые аргументы дают одинаковые
   байты в файле; 100×40 = 4040 байт с LF; плохие аргументы/путь дают код 2
   без traceback. Атомарная замена CLI-файла сохраняет старые данные при
   имитированной ошибке публикации; интерактивный экспорт не перезаписывает файл.
5. **Контроллер:** mode switch сохраняет идентичность Tree; все действия,
   reset, анимация/пауза, предельные масштабы/наклоны, export и cleanup при
   Ctrl+C. Последовательность resize 100×40 → 20×5 → 80×30 → 1×1 проверена
   в production UI-loop с подставным терминальным адаптером. Это симуляция
   размеров, а не проверка оконного менеджера Windows Terminal.

## PASS — реальная Windows PTY

В native PTY запущено приложение с настоящими stdin/stdout TTY, Win32
console API и `msvcrt`, а не только fake terminal из тестов.

- Старт/конечный выход seed 137 / 3D / `--frames 2`: код приложения **0**.
  [`verification/native-startup.json`](verification/native-startup.json).
- Интерактивная сессия seed 42: `1/2/3`, Right, `]`, `H`, `E`, `+`, `G`,
  `R`, Space/пауза, Esc. Видны смена режимов, yaw 25→33, XW 0→8, seed
  42→43, изменение проекции и PLAY/PAUSED. Экспорт записан из живой сессии.
  Выход Esc — **0**. [`verification/native-controls.json`](verification/native-controls.json).
- Отдельная сессия 4D завершена настоящим введённым Ctrl+C. Код приложения
  **130**. [`verification/native-ctrl-c.json`](verification/native-ctrl-c.json).
- Во всех трёх записанных проверках input/output console modes до и после
  совпали: **[503, 7] → [503, 7]**. В выводе видны возврат курсора и выход
  из alternate screen. PowerShell-обёртка отображает ненулевой native exit
  как собственный код 1; JSON хранит именно код приложения 130.

В ходе разработки исправлены два подтверждённых дефекта: утолщение дочерней
ветви при ответвлении и потеря Ctrl+C в PowerShell-hosted PTY. Последняя
версия повторно проверена; незакрытых падений финального набора нет.

Повторить native-пробу можно из терминала:

```powershell
python tools/native_probe.py --report verification/local-check.json --seed 42 --mode 4d
```

Нажмите нужные клавиши и Q/Esc/Ctrl+C. Проба пишет код и состояния консоли.
Полный сценарий: [`DEMO.md`](DEMO.md).

## Производительность

Последний конечный benchmark: 10 кадров каждого режима, seed 42, 100×40,
`time=0..0.9`. Медиана 2D **18.34 мс**, 3D **20.50 мс**, 4D **26.58 мс**;
максимум 4D **38.44 мс**. Это измерение данного окружения, не обещание скорости
на другом устройстве. UI добавляет паузу между кадрами и обновляет экран на
месте; остановленный экран не перерисовывается без input/resize.

## NOT RUN / ограничения

- Не запускался GUI Windows Terminal; физический resize окна и конкретные
  шрифты требуют ручного сценария из DEMO. Native PTY обычно была 80×24;
  headless 100×40 и различные размеры UI проверены отдельно.
- Реальная Linux/WSL-сессия не запускалась. POSIX-адаптер присутствует,
  но native termios/escape-key поведение здесь не подтверждено.
- Опциональная установка пакета `pip install .` и entrypoint `ascii-tree`
  не проверялись; запуск модуля без установки проверен.
- Сильный zoom/XW может намеренно обрезать дерево; depth/surface shading
  приближённые. Подробные trade-offs: [`IMPLEMENTATION_NOTES.md`](IMPLEMENTATION_NOTES.md).

Глобальный skill `codex-flow` недоступен по политике доступа; использованы
предоставленные локальные инструкции. Единственный reviewer сделал начальную
read-only проверку требований без файлов и инструментов; исходники написаны
и интегрированы координатором.
