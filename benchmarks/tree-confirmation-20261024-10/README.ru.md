Лимиты прежние: 1500 секунд и 80 запросов на ветку. Время остановки Solo не
является временем завершения; отношение успешных времён A/B остаётся null.
Процент ускорения из таймаута не вычисляется. Оба артефакта приняты по исходному
правилу «не меньше 80 баллов и пять критических условий», но это не означает
выполнение каждого требования. У Solo отсутствует README, а буквальный Ctrl+C
не завершил приложение в фиксированном SDK/ConPTY-контексте без исправления
обработчиков. Его собственный тест сбрасывает обработку сигнала и не заменяет
независимую проверку. q/Esc, изменения размера и 3D round trip прошли.

## Качество и проверяемые результаты

Новый слепой проверяющий зафиксировал все 26 оценок до раскрытия соответствия A/B.
Преимущество Flow связано с надёжностью, тестами, сопровождаемостью и README.
У Solo выше эстетика: 10/12 против 8/12, а также категории 2D/3D. У Flow
приближённая интерполяция глубины на экране; общий балл не доказывает лучшую
картинку во всех категориях. Подробности сохранены в [слепом разборе](evidence/blind-review.md).

У Flow геометрические пробы — 138/138. У Solo — 84 успешные и 38 сохранённых
дополнительных сбоев на нечисловых входах. Основные проверки полной конечной
модели, ранга, W, вращений и последовательной проекции прошли. Числа проб
различаются из-за разных открытых API и не превращаются в нормализованный балл.
Приватная проекция Flow наблюдалась временным read-only profiler внутри SDK;
прежний profiler восстановлен. Исходники, globals, входы и обработчики управления
приложения не подменялись.

Все 72 отобранных файла сохранены побайтно в [solutions](solutions). Повторов
генерации, исправлений приложений и изменений оценок не было. Сохранён неуспешный
native-отчёт Solo. Очищенные отчёты имеют отдельные исходные и опубликованные SHA;
код, оценщики и ASCII-кадры копируются без изменений. Два execution sidecar
headless-запуска принадлежат координатору и явно отмечены как находящиеся вне
seal проверяющего в [provenance](results-publication.json). Сырые VT-потоки,
native-базы, авторизация и приватные карты остаются локально.

## Что изменилось

Точные 16 файлов runtime из development commit
`8d3913cbee77cc91c482a13fed12c031170d4594` находятся в [frozen-runtime](frozen-runtime).
От прежней серии отличаются только инструкции координации CLI/native. Провайдер,
транспорт, исходные байты inference-запросов, выключенный suffix, sandbox,
дедлайн и механизм ограничения запросов сохранены.

Первый reviewer/high выполнил один реальный запрос, главный агент — Sol XHigh.
Успешных budget-status вызовов было два против шести в прежнем Tree Flow.
Исторически запросов стало 38 вместо 40, но запросов главного XHigh — 37 вместо
35. Эти различия не доказывают экономию времени или квоты. Полный usage Flow:
2 382 661 input и 48 580 output tokens. Полный usage Solo неизвестен; нижняя
граница по 24 завершённым запросам — 1 132 428 input и 43 248 output tokens.

Последний запрос Solo получил HTTP200 и был прерван контроллером при чтении тела
с причиной `control/deadline_exhausted`. Проверенный terminal event не получен,
usage остаётся null. Это не зарегистрированный `upstream_read_error`. У Flow
успешен один бесплатный Mercury-вызов; онлайн-проб Harness нет. Платные API
не подключались. [Реальная предварительная проверка](prerequisite-result.json)
прошла 21/21 за шесть запросов и не засчитывается в бенчмарк.

## Запуск работающего Flow-демо

```powershell
Push-Location benchmarks/tree-confirmation-20261024-10/solutions/B
python -m ascii_tree view --seed 42 --mode 4d
Pop-Location
```

`1`, `2`, `3` переключают 2D/3D/4D; `[` и `]` вращают XW; `q` завершает работу.
Сохранены настоящие экспорты [2D](evidence/frozen-23/2d-42.txt),
[3D](evidence/frozen-23/3d-42.txt), [4D](evidence/frozen-23/4d-42.txt) и 108 ASCII-кадров.
Для демо нужны Python, без модельного аккаунта и установки пакетов. Native-проверка
выполнена в Windows SDK/ConPTY; видимое GUI/шрифт и Linux-управление этих замороженных
приложений отдельно не проверялись.

Исходная [отрицательная серия из трёх задач](../stream-suite-20261024-01/README.ru.md)
сохранена целиком. Новый запуск не заменяет её и тоже не прошёл строгое условие
ускорения. Общий native-state и ограниченная физическая изоляция чтения остаются
явными ограничениями. [Откат](../../docs/rollback.md) сохраняет текущие правки и
настройки основного компьютера.
