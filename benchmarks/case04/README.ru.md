# Case04: реальные результаты, неполная проверка полного flow

Запрошен Sol 6.1 XHigh; параллельно A/B, затем C/D, один scaffold и лимит 1500 секунд/ветку. Слепая оценка завершила все 26 критериев и приняла четыре артефакта; статусы процессов сохранены:

| Ветка | Артефакт /100 | Полное время, с | Исходный статус | Native-запросы, включая пробы |
|---|---:|---:|---|---:|
| A | 89 | 1501.000 | `timed_out` | 24 |
| B | 83 | 1501.375 | `timed_out` | 39 |
| C | 96 | 1475.578 | `completed_unverified` | 24 |
| D | 90 | 1501.344 | `timed_out` | 42 |

Ограничение доступа к метаданным при слепой оценке сохранено в JSON.

**Полный A/B-flow — BLOCKED:** помощники B/C/D не наблюдались; строгая изоляция профилей/состояния/глубины не подтверждена. Mercury: по одному успеху B/C; локальные Harness²-inspired пробы: по две B/D. Upstream-исполнитель исключён. Причинный вклад и ускорение не доказаны.

Все решения прошли независимую проверку 4D и одинаковую CLI-матрицу из 20 кадров. Frozen-discovery B/D: not-assessed из-за отсутствующих CLI-инструкций; нормализации нет. Исходные тесты: A33 прошли, B25 запускались/две ошибки fixtures, C35/D43 прошли. Native: A/B по 55 успехов и таймаут Ctrl+C; C/D по 57. Дополнительный smoke не отменяет ошибок.

Полный aggregate только у C: 1183819 входных, 44500 выходных, 109696 cached-токенов. A/B/D: один незавершённый запрос, aggregate null; нижние границы завершённых запросов всех фаз сохранены отдельно. Накопительные бюджеты не складывались. Деньги/квота неизвестны. RSS/CPU — выборочные root-PID без потомков/удалённой модели.

Лимит не равен времени завершения. Этот эксперимент с другим runtime не объединяется с case02. ZIP локальные; промпты, native-базы/журналы, авторизация, stderr и личные пути не публикуются.
