# Демонстрации ASCII Tree Explorer

[English](README.md) · [Результаты case02](../../benchmarks/case02/results.json)

Сохранены две независимо оценённые реализации case02. Их код не объединялся:

| Каталог | Исходная ветка / анонимный ID | Оценка артефакта | Статус процесса |
|---|---|---:|---|
| [solo](solo/README.md) | A / solution-2 | 95/100 | `timed_out` |
| [flow](flow/README.md) | B / solution-1 | 97/100 | `timed_out` |

Приложения приняты после независимой проверки, но статус процессов сохранён. Это не доказывает ускорение полной архитектуры: в case02 было 0 успешных Mercury-вызовов, а работа нативных помощников не подтверждена.

Нужны Python 3.12+ и обычный терминал; сторонних зависимостей, API-ключей, GPU и сервисов нет. Для автоматического запуска используйте `render`: поведение `view` без TTY у реализаций различается.

## PowerShell

Из корня репозитория выберите `solo` либо `flow`:

```powershell
$variant = 'solo' # для ветки B замените на 'flow'
Push-Location (Join-Path 'examples/ascii-tree' $variant)
python -m ascii_tree --help
python -m ascii_tree view --seed 42 --mode 3d
Pop-Location
```

## Linux / WSL

Из корня репозитория:

```bash
cd examples/ascii-tree/solo # либо examples/ascii-tree/flow
python3 -m ascii_tree --help
python3 -m ascii_tree view --seed 42 --mode 3d
```

Управление: `1`/`2`/`3` — 2D/3D/4D, стрелки — камера, `[`/`]` — угол 4D, `H` — справка, `E` — экспорт, `Q` — выход. Реальные флаги и особенности описаны в README каждого варианта. Общие команды:

```text
python -m ascii_tree render --seed 42 --mode 4d --width 100 --height 40 --output frame.txt
python -m unittest discover -s tests -v
```

Одинаковую команду тестирования следует выполнять отдельно в каждом варианте. **При упаковке приложение, импорты, тесты и CI не запускались.** Проверки case02 — исторические свидетельства. Файл [flow/VERIFICATION.md](flow/VERIFICATION.md) добавлен после оценки для исправления отсутствовавшей ссылки; баллы не менялись.

## Последующая проверка копий

После упаковки в Windows sandbox прошли **35 тестов solo и 47 тестов flow**. Для обеих копий headless-проверка 2D/3D/4D подтвердила ASCII, размеры, побайтовую повторяемость и различия между seed. Интерактивный терминальный сценарий этим smoke не запускался. Это новая проверка упакованных копий, отдельно от исходных баллов case02.

Linux CI для примеров ожидается. Ни исторические отчёты, ни локальная проверка Windows не означают успешный CI последней версии; подтверждённые границы указаны в [статусе приёмки](../../docs/acceptance-status.md).

В `provenance.json` указаны исходные ветка/ID, SHA256 кода после нормализации LF, состав копии и отличия документации. Код скопирован без изменений. Статические ASCII-примеры сохранены как необходимые тестовые данные. Экспорты, логи, записи терминала, Git/native-состояние, базы, журналы, ключи и временные каталоги исключены. Оригиналы не изменялись; пропуски исторических материалов объясняет `PACKAGING.md` каждого варианта.
