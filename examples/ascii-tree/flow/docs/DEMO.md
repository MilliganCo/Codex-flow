# Демонстрация в Windows Terminal / PowerShell 7

Откройте каталог проекта; моноширинный шрифт, окно примерно 100×40.
Сценарий занимает около 2 минут. Автоматическое воспроизведение без видимого окна:
`python scripts/terminal_smoke.py`.

1. Запустите `python -m ascii_tree view --seed 42 --mode 2d`. Нажмите `H`,
   проверьте раскладку, снова `H`. Видны основание, сужающийся ствол, крупные
   и мелкие ветви, разреженная листва. Нажмите `E`: в `exports/` появился
   прямоугольный ASCII-файл без текста меню.
2. Нажмите `2`. Seed остается 42. Нажмите правую стрелку 5 раз, затем верхнюю
   2 раза: меняются взаимное положение ветвей и перекрытия. Проверьте `+`/`-`.
   `R` возвращает исходный ракурс. `Space` включает вращение; снова `Space`
   останавливает его без прокрутки терминала.
3. Нажмите `3`, затем `E`. Вверху написано `4D data -> 3D -> 2D`, W — возраст
   ветви. Нажмите `]` 8 раз и `E`: сравните два последних файла. `[` вращает
   обратно. Seed не меняется, а форма меняется из-за смешивания X и W.
4. Нажмите `G`: seed становится 43 и появляется другое дерево. Для второго
   фиксированного примера можно перезапустить с `--seed 7`. Уменьшите окно до
   30×12, затем максимально узкого, верните 100×40: приложение не падает,
   интерфейс и рисунок восстанавливаются. В узком окне текст обрезается.
5. Нажмите `Q`: прежний экран и курсор восстановлены. Повторите запуск
   и завершите через `Esc`, затем еще раз через `Ctrl+C`. После каждого выхода
   убедитесь, что обычный ввод PowerShell не потерял эхо и курсор видим.

Проверка перенаправления и headless, отдельно от интерактивного запуска:

```powershell
python -m ascii_tree render --seed 42 --mode 4d --angle4d 65 --output check.txt
"" | python -m ascii_tree view --seed 42
```

Первая команда создает `check.txt`. Вторая сразу сообщает, что нужен TTY,
и завершается с кодом 2. Удалять созданные файлы для работы приложения не нужно.

В этой среде автоматически проверен настоящий Windows ConPTY. Визуальная
оценка в открытом окне Windows Terminal и Linux/WSL остаются ручными проверками;
они не объявлены выполненными.
